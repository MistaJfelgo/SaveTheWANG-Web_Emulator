Your first few minutes with a Wang


Welcome aboard! This Wang has a few keys of its own. Here's the easy route in.


  1. Leave the defaults and click Start this Wang. PCXC5-3 starts with System 2.01 already installed on Winchester C. Leave floppy A empty. Every visitor gets private disk copies.
    2. 

  2. Give it a moment. The progress message shows the downloads. The real firmware then runs its startup checks.
    3. 

  3. At the date screen: click the Wang screen, type six digits for the date (MMDDYY), press Enter to move to time, and type HHMMSS. An era-appropriate date such as 102986 is fine. Press Insert or the page's Execute button to continue. (Sorry, WANG didn't exist long enough to be Y2K compliant.)
    4. 

  4. At the Wang menu: press Space to move the selection. Press Insert / Execute to open it. Choose DOS Command Processor to reach a command prompt.
    5. 

  5. Try a disk! Pick an MFI in the A dropdown or Browse disk library, then insert it in A. In DOS, type DIR A: and press Enter to see its files. Try IMG if you want to compare another recovery of the same disk.


The keys to remember
Insert = Wang Execute
Opens a menu selection or confirms a Wang screen. The on-page Execute button works too.
Enter = Wang Return
Moves to the next field, or runs a command at the DOS prompt.
Space
Moves the highlighted choice in the main menu.
Cancel button
Sends the Wang Cancel key. Escape is mapped to Wang Help, so it isn't a universal Cancel key.


Disks, resets and goodbyes
Wait for disk activity to finish before swapping. Eject removes a floppy without losing its working copy. Before Reset, eject an application disk from A or choose a confirmed bootable disk. The menu and DOS may ask you to put the system disk back for COMMAND.COM; that's normal old-school disk juggling.


Save this session's disks keeps your changes in this browser. Turn Off offers to save first. Later, choose your saved disks before starting. These are disk saves, so the machine boots again rather than resuming the same screen. Clearing this site's browser data removes local saves.


Want the full installation adventure? Choose an initialized Winchester to install the OS, or an uninitialized one to run INITW from Winchester Utilities first. The ready-to-use default is the easiest starting point.


Keyboard input on phones is still limited: a canvas doesn't automatically open the phone's keyboard. A desktop or an external keyboard is the best option for now.



Turn off this Wang?
Save your disks to keep your changes in this browser. Turning off stops this session and returns to the start screen.



Disk library


Original captures stay in the preservation archive. MFI flux conversions are preferred; IMG derivatives remain available for comparison and community testing; some may fail to load or contain damaged sectors. Before startup, only confirmed bootable floppies can be selected. After boot, insert any available image. Please report the disk ID, filename and result through the project contact page.
